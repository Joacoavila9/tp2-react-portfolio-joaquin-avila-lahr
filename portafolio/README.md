## Descripción del Proyecto

Este proyecto consiste en un portfolio personal desarrollado con React y Vite como segundo Trabajo Práctico de la materia Programación 4.

La aplicación presenta información personal, habilidades, proyectos y datos de contacto mediante diferentes páginas. Se utilizan componentes reutilizables, paso de información mediante props, renderizado dinámico de datos mediante `.map()`, manejo de estados interactivos con `useState` y navegación entre páginas mediante React Router DOM.

El portfolio cuenta con las siguientes secciones:

- Inicio.
- Sobre mí.
- Habilidades.
- Proyectos.
- Contacto.

## Instalación de Dependencias

Para instalar las dependencias necesarias del proyecto, seguir los siguientes pasos:

**1. Clonar el repositorio:**

```bash
git clone URL_DEL_REPOSITORIO
```

Reemplazar `URL_DEL_REPOSITORIO` por la dirección del repositorio de GitHub correspondiente al TP2.

**2. Ingresar a la carpeta del proyecto:**

```bash
cd portafolioReact
```

**3. Instalar las dependencias:**

```bash
npm install
```

Este comando instala las dependencias necesarias especificadas en el archivo `package.json`.

**4. Ejecutar el proyecto en modo desarrollo:**

```bash
npm run dev
```

**5. Abrir el proyecto en el navegador:**

Ingresar a la dirección indicada por Vite en la terminal, normalmente:

http://localhost:5173
